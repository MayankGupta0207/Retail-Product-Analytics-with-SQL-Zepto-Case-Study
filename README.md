This project is a SQL-based case study inspired by **Zepto (quick commerce)**.  
It demonstrates how SQL can be used for **data exploration, cleaning, and business insights generation** in the retail/e-commerce domain.  

---

## 📂 Project Structure
- **Table Creation**: Defines schema for product inventory (category, MRP, discounts, stock, weight, etc.).  
- **Data Exploration**: Row counts, duplicates, missing values, product categories, stock status.  
- **Data Cleaning**: Handle invalid prices, standardize units (paise → rupees).  
- **Data Analysis**: 21+ queries answering real-world business questions.
